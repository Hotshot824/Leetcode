### [1716. Calculate Money in Leetcode Bank]

[1716. Calculate Money in Leetcode Bank]: https://leetcode.com/problems/calculate-money-in-leetcode-bank/?envType=daily-question&envId=2025-10-25

很簡單的題目，應該有數學的解法，但最直接的方式就是模擬存錢的過程。

題目如下：
-   A 每週都會存錢，第一週從 1 元開始存，每天比前一天多存 1 元
-   接下來的每週會比上週的起始多存 1 元
-   輸入 n 天，求總共存了多少錢

Time Complexity: O(n)

**Golang Solution:**
```go
func totalMoney(n int) int {
    res := 0
    start := 1
    for n > 0 {
        for i := 0; i < 7 && n > 0; i++ {
            res += start + i
            n--
        }
        start++
    }
    return res
}
```
