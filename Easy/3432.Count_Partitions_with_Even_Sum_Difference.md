### [3432. Count Partitions with Even Sum Difference]

[3432. Count Partitions with Even Sum Difference]: https://leetcode.com/problems/count-partitions-with-even-sum-difference/

這題要計算一個 Array 可以被分成兩個子集合，且兩個子集合的和的差是偶數的方式數量。

---

### Brute Force

這題可以 Brute Force 的方式來解題，直接照題目敘述做在 O(n<sup>2</sup>) 的時間內解出來。

1. Traverse all possible partitions of the array into two subsets.
2. For each partition, calculate the sums of both subsets.
3. Check if the difference between the two sums is even.
4. Count the number of valid partitions.

Time Complexity O(n<sup>2</sup>), Space Complexity O(1).

**Golang Solution**
```go
func countPartitions(nums []int) int {
    res := 0
    for i := 1; i < len(nums); i++ {
        left := sum(nums[:i])
        right := sum(nums[i:])
        
        if (left - right) % 2 == 0 {
            res++
        }
    }
    return res
}

func sum(nums []int) int {
    res := 0
    for _, v := range nums {
        res += v
    }
    return res
}
```

**CPP Solution**
```cpp
int sumPartitionsArray(int* nums, int left, int right) {
    int res = 0;
    for (int i = left; i < right; i++) {
        res += nums[i];
    }
    return res;
}

int countPartitions(int* nums, int numsSize) {
    int res = 0;
    for (int i = 1; i < numsSize; i++) {
        int left = sumPartitionsArray(nums, 0, i + 1);
        int right = sumPartitionsArray(nums, i + 1, numsSize);
        if ((left - right) % 2 == 0) {
            res++;
        } 
    }
    return res;
}
```

### Math

-   先思考一個問題，如果整個 Array 的和是奇數，是否能夠被分成兩個子集合使得兩個子集合的和的差是偶數？
    -   無法，這代表整個 Array 中有奇數個奇數，因此無論如何分割都會有一邊的 Subset 和是奇數，另一邊是偶數，兩者差值一定是奇數
-   如果整個 Array 中的奇數是偶數個是否代表就一定能夠分成兩個子集合使得兩個子集合的和的差是偶數？
    -   可以，因為我們可以把奇數兩兩配對放在同一個 Subset 中，這樣兩個 Subset 的和一定都是偶數，因此差值也是偶數
-   `[2, 3, 1, 4, 1, 3]` 在這個 Array 中無論在哪裡切割都會使左右相減後成為可以被 2 整除的數字，因為這個 Array 中有 4 個奇數。
    -   `(2, 3) | (1, 4, 1, 3)` => `5 - 9 = -4`
    -   `(2, 3, 1) | (4, 1, 3)` => `6 - 8 = -2`
    -   `(2, 3, 1, 4) | (1, 3)` => `10 - 4 = 6`
    -   `(2, 3, 1, 4, 1) | (3)` => `11 - 3 = 8`
-   這證明了只要 Array 中的奇數是偶數個，那麼無論在哪裡切割都會使兩個子集合的和的差是偶數。

因此我們只要計算 Total 是否為偶數，若是偶數則回傳 `n - 1`，否則回傳 `0` 即可。

Time Complexity O(n), Space Complexity O(1).

**C Solution**
```c
int countPartitions(int* nums, int numsSize) {
    int total = 0;

    for (int i = 0; i < numsSize; i++)
        total += nums[i];

    return total % 2 == 0 ? numsSize - 1 : 0;
}
```
