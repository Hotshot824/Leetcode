### [105. Construct Binary Tree from Preorder and Inorder Traversal]

[105. Construct Binary Tree from Preorder and Inorder Traversal]: https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/

這題會給兩個 Array，分別是 Binary Tree 的 Preorder 與 Inorder Traversal，要求我們根據這兩個 Array 重建出原本的 Binary Tree。

---

### Recursive Solution

首先要先清楚 Preorder 與 Inorder 的 Traversal 順序:
-   Preorder: Root -> Left -> Right
-   Inorder: Left -> Root -> Right

![](https://assets.leetcode.com/uploads/2021/02/19/tree.jpg)

以上面的例子來說，Preorder 為 [3,9,20,15,7]，Inorder 為 [9,3,15,20,7]。

這裡我們可以注意到的一件事是，Preorder 的第一個元素必然是整個樹的 Root，
而 Inorder 中 Root 的位置則可以將整個樹分成左子樹與右子樹兩部分。

因此整個解題的目標就是不斷依據 Preorder 的第一個元素來找到 Root，重建該 Root。然後依據這個 Root 在 Inorder 中的位置來分割出左子樹與右子樹的範圍，接著對這兩個子樹重複相同的過程。

Example:
```
Preorder: [3,9,20,15,7]
　　　　　　^
Inorder:  [9,3,15,20,7]
             ^
(Root: 3)

>Left Subtree [9]:

Preorder: [9,20,15,7]
　　　　　　^
Inorder:  [9]
           ^
(Root: 9, No Left or Right Subtree)

>Right Subtree:

Preorder: [20,15,7]
　　　　　　^
Inorder:  [15,20,7]
              ^
(Root: 20)

...
```

這裡我們重建的過程可以使用遞迴 (Recursion) 來實現，並且使用一個 HashMap 來記錄 Inorder 中每個值的位置，這樣可以在 O(1) 的時間內找到 Root 在 Inorder 中的位置。

在遞迴函式中，我們需要傳入 Preorder 陣列以及 Inorder 的左右邊界 (inL, inR)，以便我們知道目前處理的子樹範圍。每次呼叫遞迴時，我們會:
1. 從 Preorder 中取出當前的 Root 值，並建立一個新的 TreeNode
2. 使用 HashMap 找到這個 Root 在 Inorder 中的位置
3. 根據這個位置，計算出左子樹與右子樹的範圍，並遞迴呼叫建立左子樹與右子樹
    -   Preorder 同樣會隨著每次建立 Root 而前進因此不會發生左右子樹範圍錯亂的問題
4. 最後回傳建立好的 Root 節點

Time Complexity: O(N), N is the number of nodes.  
Space Complexity: O(N), for the HashMap and recursion stack.

**CPP Solution:**
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left),
 * right(right) {}
 * };
 */
class Solution {
public:
    std::unordered_map<int, int> in_pos;
    int pre_idx = 0;

    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        for (int i = 0; i < inorder.size(); i++)
            in_pos[inorder[i]] = i;

        return build(preorder, 0, preorder.size() - 1);
    }

    TreeNode* build(std::vector<int>& preorder, int inL, int inR) {
        if (inL > inR)
            return nullptr;

        int rootVal = preorder[pre_idx++];
        TreeNode* root = new TreeNode(rootVal);

        int mid = in_pos[rootVal];

        root->left = build(preorder, inL, mid - 1);
        root->right = build(preorder, mid + 1, inR);

        return root;
    }
};
```
