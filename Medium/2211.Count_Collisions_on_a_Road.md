### [2211. Count Collisions on a Road]

[2211. Count Collisions on a Road]: https://leetcode.com/problems/count-collisions-on-a-road/

題目會給定一個 Array 代表每台車的車頭行駛方向，`'L'` 代表往左，`'R'` 代表往右，`'S'` 代表靜止不動，然後會要求我們計算所有車子發生碰撞的次數。

---

### Count Collisions

這題雖然直覺上會用 Stack 來處理，不過其實不需要這麼麻煩，我們只需要計算所有會發生碰撞的車子數量就可以了。

-   Example `LLRSLLRR`，觀察這個 Array 會發現以下規律:
    1.  最左側的連續 `L` 不可能發生碰撞，因為它們都往左開
    2.  最右側的連續 `R` 不可能發生碰撞，因為它們都往右開
    3.  中間的車只要是 `L` 或 `R` 就一定會發生碰撞，因為 `L` 會撞到左邊的車，`R` 會撞到右邊的車
    3.  我們只去紀錄造成碰撞的那一方的碰撞次數，因此 `L` 碰撞算 1 次，`R` 碰撞算 1 次，`S` 不會增加碰撞次數

這樣我們只要記錄去除掉最左側連續 `L` 與最右側連續 `R` 之後，剩下的車子中 `L` 與 `R` 的數量總和，就是碰撞次數。

Algorithm:
1.  Using two pointers to skip all leading 'L's and trailing 'R's.
2.  Traverse the remaining cars:
    -   If the car is 'L' or 'R', increment the collision count. 
3.  Return the total collision count.

Time Complexity O(n), Space Complexity O(1).

**Golang Solution:**
```go
func countCollisions(directions string) int {
    n := len(directions)
    left, right := 0, n-1
    
    for left < n && directions[left] == 'L' {
        left++
    }
    
    for right >= 0 && directions[right] == 'R' {
        right--
    }
    
    res := 0
    for i := left; i <= right; i++ {
        if directions[i] != 'S' {
            res++
        }
    }
    
    return res
}
```

**C Solution:**
```c
int countCollisions(char* directions) {
    int len = strlen(directions);
    int left = 0, right = len-1;

    while (left < len && directions[left] == 'L') {
        left++;
    }

    while (right >= 0 && directions[right] == 'R') {
        right--;
    }

    int res = 0;
    while (left <= right) {
        if (directions[left] != 'S') {
            res++;
        }
        left++;
    }
    return res;
}
```
