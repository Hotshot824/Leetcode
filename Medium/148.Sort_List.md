### [148. Sort List]

[148. Sort List]: https://leetcode.com/problems/sort-list/

> 以前都是用 Array 偷懶把要排序的 List 內容存起來排序完再塞回去，這題就來用 Merge Sort

複習一下 List 的 Sort，這題是要把一個 Linkedlist 做排序，最適合 Linked List 的排序演算法是 Merge Sort，因為它可以達到 $O(n \log n)$ 的時間複雜度。

主要步驟：
1. 使用快慢指標找到中間節點 (Find Middle)。
2. 切斷 List 變成兩半。
3. 遞迴排序左右兩半。
4. 合併兩個已排序的 List (Merge Two Sorted Lists)。

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
typedef struct ListNode ListNode;

ListNode* find_mid_prev(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head->next;

    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

ListNode* merge(ListNode* l1, ListNode* l2) {
    ListNode dummy;
    ListNode* tail = &dummy;

    while(l1 && l2) {
        if (l1->val < l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail=tail->next;
    }

    tail->next = l1 ? l1 : l2;
    return dummy.next;
}

struct ListNode* sortList(struct ListNode* head) {
    if (head == NULL || head->next == NULL) {
        return head;
    }

    ListNode* mid = find_mid_prev(head);
    ListNode* right = mid->next;
    mid->next = NULL;

    head = sortList(head);
    right = sortList(right);

    return merge(head, right);
}
```
