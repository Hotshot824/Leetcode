### Brute Force Solution

最樸素的做法就是逐一計算每個位置能儲存的雨水：
1. 對於每個位置，找到左邊最高點和右邊最高點。
2. 該位置的儲水量 = min(左邊最高, 右邊最高) - 目前高度。
3. 把所有位置的儲水量加起來就是答案。

這個方法的缺點是對於每個位置都要掃描整個左邊和右邊，導致時間複雜度是 O(n<sup>2</sup>)。

Time Complexity O(n<sup>2</sup>), Space Complexity O(1).

**Go Solution:**
```go
func trap(height []int) int {
	var sum int
	for i := 0; i < len(height); i++ {
		if i == 0 || i == len(height)-1 {
			continue
		}
		l, r := i-1, i+1
		Rh, Lh := height[i], height[i]
		for ; l >= 0; l-- {
			if height[l] > Lh {
				Lh = height[l]
			}
		}
		for ; r < len(height); r++ {
			if height[r] > Rh {
				Rh = height[r]
			}
		}
		h := min(Lh, Rh) - height[i]
		if h > 0 {
			sum += h
		}

	}
	return sum
}

func min(i, j int) int {
	if i > j {
		return j
	}
	return i
}
```

### Scan Left And Right Max Height

我們知道每個位置的儲水量取決於該位置左邊和右邊的最高點，因此我們可以事先計算出每個位置的左邊最高點和右邊最高點，然後再一次掃描陣列來計算儲水量。這樣只需要掃描陣列三次，時間複雜度是 O(n)。

1. 從左往右掃描，記錄每個位置的左邊最高點。
2. 從右往左掃描，記錄每個位置的右邊最高點。
3. 再次從左往右掃描，計算每個位置的儲水量，並加總。

**CPP Solution:**
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        std::vector<int> left_max(n, 0);
        std::vector<int> right_max(n, 0);

        int m = 0;
        for (int i = 0; i < n; i++) {
            m = max(m, height[i]);
            left_max[i] = m;
        }

        m = 0;
        for (int i = n - 1; i >= 0; i--) {
            m = max(m, height[i]);
            right_max[i] = m;
        }

        int res = 0;
        for (int i = 0; i < n; i++) {
            int w = min(left_max[i], right_max[i]) - height[i];
            res += w;
        }
        return res;
    }
};
```

### Two Pointer Solution:

這個方法使用兩個指針 start 和 end 來掃描陣列：
1. 如果找到 end 位置的高度 >= start 位置的高度，就計算這兩點之間的儲水量，然後把 start 移到 end。
2. 如果 end 掃到陣列末尾還沒找到更高的位置，就把 start 之後的陣列反轉，重新從新起點開始掃。
3. 重複這個過程直到 start 掃完整個陣列。

Time Complexity O(n), Space Complexity O(1).

```

 |->|  -> |   ->      |          ->   
 0  1     4           R           N

[1, 2, 1, 2, 3]
 |->|  -> |->|
 0  1     0  E

 1 + 4 + 1 = 6
```

This time complexity is O(n<sup>2</sup>), but usually faster than brute force solution.
```go
func trap(height []int) int {
	var result int
	var start, end int = 0, 0
	for ; start < len(height)-1; end++ {
		// End move to the last element, reverse last element to array
		if end > len(height)-1 {
			height = reverse(height[start:])
			start, end = 0, 0
		}
		if height[start] <= height[end] {
			result += cap(height, start, end)
			start = end
		}
	}
	return result
}

// Calculate the capacity between two heights
func cap(height []int, left, right int) int {
	cap := min(height[left], height[right])
	var sum int = 0
	for i := left + 1; i < right; i++ {
		sum += cap - height[i]
	}
	return sum
}

func min(i, j int) int {
	if i > j {
		return j
	}
	return i
}

func reverse(arr []int) []int {
	for i, j := 0, len(arr)-1; i < j; i, j = i+1, j-1 {
		arr[i], arr[j] = arr[j], arr[i]
	}
	return arr
}
```
