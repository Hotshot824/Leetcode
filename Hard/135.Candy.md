### [135. Candy]

[135. Candy]: https://leetcode.com/problems/candy/

這題給了一個 Array，代表每個小朋友的評分，要求我們分配糖果給這些小朋友，規則是每個小朋友至少要有一顆糖果，且評分較高的小朋友要比鄰近評分較低的小朋友得到更多的糖果，問我們最少要分配多少糖果。

-   Ratings: [1,0,2]
    -   index 0 greater than index 1, so index 0 must have more candies than index 1.
    -   index 2 greater than index 1, so index 2 must have more candies than index 1.
    -   We can distribute to the three children with 2, 1, 2 candies respectively.
    -   Candy: [2,1,2], minimum candies needed is 5.

---

### Two Scan Solution

這題很容易想到複雜的作法，我一開始想用 Map 去解，從最低分的位置開始分配糖果，這樣就每次檢查鄰近位置的評分來決定要分配多少糖果，但就要用一個 Map 去記錄每個位置的糖果數量，程式碼會比較複雜。

-   其實只要掃瞄兩次 Array 就可以解決這個問題，先初始化每個位置的糖果數量都是 1
    1.  從左往右掃描，每次檢查比左邊大的位置，糖果數量就比左邊多一顆糖果。
    2.  從右往左掃描，每次檢查比右邊大的位置，糖果數量就比右邊多一顆糖果。
    3.  最後把每個位置的糖果數量加總起來就是答案。

```
[1, 0, 2, 3, 2, 1]

Left to Right Scan:
[1, 1, 2, 3, 1, 1]

Right to Left Scan:
[2, 1, 2, 3, 2, 1]
```

Time Complexity O(n), Space Complexity O(n).

**CPP Solution:**
```cpp
class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        std::vector<int> count(n, 1);

        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1])
                count[i] = count[i - 1] + 1;
        }

        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1])
                count[i] = max(count[i], count[i + 1] + 1);
        }

        int res = 0;
        
        for (auto& c : count)
            res += c;

        return res;
    }
};
```
