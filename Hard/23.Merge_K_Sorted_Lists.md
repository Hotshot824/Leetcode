### Merge each two lists ( O(kN) )

如果先寫過 [21. Merge Two Sorted Lists]，應該會想到這個做法，
每次合併兩個 list，直到所有 list 都合併完。

1. Initialize the result list as the first list.
2. Iterate through the remaining lists, merging each one with the result list using the two-list merge function.
3. Return the merged result list.

雖然可以 Accepted，但間複雜度較高，當 k 很大時會很慢。因為不停地往已合併的 list 裡面插入 node，
這條 list 會越來越長，導致時間越來越慢。

Time Complexity: O(kN), N is the total number of nodes across all lists, k is the number of lists.

[21. Merge Two Sorted Lists]: https://leetcode.com/problems/merge-two-sorted-lists

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* merge(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode tmp;
    struct ListNode* cur = &tmp;
    while (l1 && l2) {
        if (l1->val < l2->val) {
            cur->next = l1;
            l1 = l1->next;
        } else {
            cur->next = l2;
            l2 = l2->next;
        }
        cur = cur->next;
    }

    cur->next = l1 ? l1 : l2;
    return tmp.next;
}

struct ListNode* mergeKLists(struct ListNode** lists, int listsSize) {
    if (listsSize <= 0) {
        return NULL;
    }

    struct ListNode* res = lists[0];
    for (int i = 1; i < listsSize; i++) {
        res = merge(res, lists[i]);
    }
    return res;
}
```

### Divide and Conquer ( O(N log k) )

實際上我們分別合併兩個 list 的時間是 O(N)，如果我們能夠把 k 個 list 切割成 log k 層，每層合併 N 個 node，整體時間就會是 O(N log k)。
這樣做的好處是每次合併的 list 都不會太長，也不會有重複合併同一個 list 的問題。

作法類似於 Merge sort:
1. 先將 k 個 list 切割到最小單位，也就是每個 list 自己
2. 再逐一合併每兩個 list 直到最後

Time Complexity: O(N log k), N is the total number of nodes across all lists, k is the number of lists.

**C Solution:**
```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* merge(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode tmp;
    struct ListNode* cur = &tmp;

    while (l1 && l2) {
        if (l1->val < l2->val) {
            cur->next = l1;
            l1 = l1->next;
        } else {
            cur->next = l2;
            l2 = l2->next;
        }
        cur = cur->next;
    }

    cur->next = l1 ? l1 : l2;
    return tmp.next;
}

struct ListNode* mergeKLists(struct ListNode** lists, int listsSize) {
    if (listsSize <= 0)
        return NULL;

    while (listsSize > 1) {
        int mid = (listsSize + 1) / 2;

        for (int i = 0; i < listsSize / 2; i++) {
            lists[i] = merge(lists[i], lists[i + mid]);
        }

        listsSize = mid;
    }

    return lists[0];
}
```

**GO Solution:**
-	The following code cuts the unit using recursion.
```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func mergeKLists(lists []*ListNode) *ListNode {
	var head *ListNode
	if len(lists) > 0 {
		mergeSort(lists, 0, len(lists)-1)
		head = lists[0]
	}
	return head
}

func mergeSort(lists []*ListNode, front, end int) {
	if front >= end {
		return
	}
	mid := (front + end) / 2
	mergeSort(lists, front, mid)
	mergeSort(lists, mid+1, end)
	Merge(lists, front, mid+1)
}

func Merge(lists []*ListNode, front, mid int) {
	virturalhead := &ListNode{}
	l1, l2 := lists[front], lists[mid]
	cur := virturalhead
	for l1 != nil && l2 != nil {
		if l1.Val > l2.Val {
			cur.Next = l2
			cur = cur.Next
			l2 = l2.Next
		} else {
			cur.Next = l1
			cur = cur.Next
			l1 = l1.Next
		}
	}
	if l1 == nil {
		cur.Next = l2
	}
	if l2 == nil {
		cur.Next = l1
	}
	lists[front] = virturalhead.Next
}
```

### Brute Force: Collect all nodes and sort them ( O(N log N) )

暴力解， collect 所有 node 到 array，排序後再塞回 linked list，
如果當下想不到 merge k sorted list 的解法，可以先用這個方法過關。

1. Collect all nodes into an array.
2. Sort the array based on node values.
3. Re-link the nodes in sorted order.

Time Complexity: O(N log N), where N is the total number of nodes across all lists.

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
typedef struct ListNode ListNode;

int cmp(const void* a, const void* b) {
    ListNode* const* x = (ListNode* const*)a;
    ListNode* const* y = (ListNode* const*)b;
    return (*x)->val - (*y)->val;
}

struct ListNode* mergeKLists(struct ListNode** lists, int listsSize) {
    int count = 0;
    for (int i = 0; i < listsSize; i++) {
        ListNode* cur = lists[i];
        while (cur) {
            cur = cur->next;
            count++;
        }
    }

    if (count == 0) return NULL;

    ListNode* arr[count];
    int idx = 0;
    for (int i = 0; i < listsSize; i++) {
        ListNode* cur = lists[i];
        while(cur) {
            arr[idx++] = cur;
            cur = cur->next;
        }
    }

    qsort(arr, count, sizeof(ListNode*), cmp);

    for (int i = 0; i < count - 1; i++) {
        arr[i]->next = arr[i+1];
    }
    arr[count-1]->next = NULL;

    return arr[0];
}
```
