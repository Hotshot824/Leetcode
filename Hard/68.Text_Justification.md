### [68. Text Justification]

[68. Text Justification]: https://leetcode.com/problems/text-justification/

很繁瑣的一題，這題的難點在於處理字串的時候要細心，尤其是空格的分配上。

題目會給一個 Array of words，和一個 maxWidth，要求我們把這些字串排版成多行，每行的長度不能超過 maxWidth，並且要符合題目要求的對齊方式。

```
Input: words = ["This", "is", "an", "example", "of", "text", "justification."], maxWidth = 16
Output:
[
   "This    is    an",
   "example  of text",
   "justification.  "
]
```

---

### Mathematical Solution

最基本的想法是先用一個 Loop traversal 所有的字串，並將字串押入目前的行 (line) 中，直到該行的長度加上下一個字串的長度會超過 maxWidth 為止。當超過時，我們就需要對目前的行進行空格分配，然後將該行加入結果中，並開始新的一行。

除了最後一行的空格分配如下：
1.  計算一共會有多少個 blank 的位置，這是 line.size() - 1
    -   這裡先假設 blank 都是 1 個空格
2.  計算目前行中所有 blank 的總長度 blank_size = maxWidth - width
3.  計算每個 blank 的基本長度 base = blank_size / blank
4.  計算剩餘的空格數量 remain = blank_size %

接著開始不是最後一行的空格分配：
-   有了上述計算之後就可以開始拼接一行，這邊 Loop 的策略是不斷將字串加入 tmp 中
    -   根據 i 是否小於 blank 來決定是否要加入空格，如果小於代表還不是最後一個字串
    -   i 的邊界是 line.size(), blank 的邊界是 line.size() - 1
-   根據 base 和 remain 來決定要加入多少空格
    -   每個 blank 最基本會加入 base 個空格
    -   如果 i < remain，代表這個 blank 需要多加入一個空格，代表還有剩餘的空格需要分配
    -   只有最後一格只需要加入 base 個空格
-   最後檢查 tmp 的長度是否小於 maxWidth，如果小於就補足空格

最後處理最後一行：
-   最後一行的處理比較簡單，直接將字串用單一空格連接起來，然後補足空格到 maxWidth 即可

Time Complexity: O(N), N is the number of words.  
Space Complexity: O(N), for the result storage.

**CPP Solution:**
```cpp
class Solution {
public:
    vector<string> fullJustify(vector<string>& words, int maxWidth) {
        std::vector<string> res = {};
        int cur = 0;
        int width = 0;
        std::vector<string> line;
        for (; cur < words.size(); cur++) {
            if (width + words[cur].size() + line.size() > maxWidth) {
                int blank = line.size() - 1;
                int blank_size = maxWidth - width;
                int base = blank ? blank_size / blank : 0;
                int remain = blank ? blank_size % blank : 0;

                std::string tmp = "";
                for (int i = 0; i < line.size(); i++) {
                    tmp += line[i];

                    if (i < blank) {
                        int spaces = base + (i < remain ? 1 : 0);
                        tmp += std::string(spaces, ' ');
                    }
                }

                if (tmp.size() < maxWidth)
                    tmp += std::string(maxWidth - tmp.size(), ' ');
                    
                res.push_back(tmp);

                line.clear();
                width = 0;
            }
            line.push_back(words[cur]);
            width += words[cur].size();
        }

        std::string tmp = line[0];
        for (int i = 1; i < line.size(); i++) {
            tmp += " " + line[i];
        }
        tmp += std::string(maxWidth - tmp.size(), ' ');
        res.push_back(tmp);
        return res;
    }
};
```
